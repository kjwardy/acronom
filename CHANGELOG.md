# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- PostgreSQL-backed acronym create, update, and delete endpoints with validation, timestamps, API documentation, and automated handler and model tests ([#9](https://github.com/kjwardy/acronom/pull/9)).
- Case-insensitive acronym search across acronym names and definitions, with exact and prefix match prioritisation, a 50-result limit, and supporting database indexes ([#12](https://github.com/kjwardy/acronom/pull/12)).
- Frontend workflows for searching, adding, editing, and deleting acronym entries, including responsive dialogs, inline validation, confirmation prompts, local result updates, and success and error feedback ([#12](https://github.com/kjwardy/acronom/pull/12)).
- Support for multiple meanings of the same acronym while preventing duplicate acronym and definition pairs.
- Dockerfile, Docker Compose configuration, entrypoint, local development instructions, deployment guidance, and contribution documentation.
- GitHub Actions validation for Go tests and vetting, PostgreSQL integration tests, frontend formatting, linting, tests, and production builds.
- GitHub Actions status badge in the README.

### Changed

- Acronym update timestamps are generated by PostgreSQL and returned from the update transaction.
- Search result links are restricted to safe HTTP and HTTPS URLs before being rendered as clickable links.
- Local React development proxies API requests to the Go service.
- API and environment configuration documentation now covers PostgreSQL, acronym management, search behavior, and local Docker development.

### Fixed

- CI database tests now initialise the application schema before cleaning test data ([#11](https://github.com/kjwardy/acronom/pull/11)).
- CI now provisions PostgreSQL and uses test-compatible application and database configuration ([#11](https://github.com/kjwardy/acronom/pull/11)).
- GitHub Actions validation now targets the correct default branch.
